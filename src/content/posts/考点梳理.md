| 技术名词 | 是什么 | 有什么用 | 备注 |
| --- | --- | --- | --- |
| 高斯泼溅（3D Gaussian Splatting/3DGS） |  用数百万个各向异性高斯椭球表示3D场景的渲染方法，每个高斯椭球由位置μ、协方差矩阵Σ（分解为旋转R和缩放S）和不透明度α描述。 | 实现实时（30+ fps）高质量3D场景渲染，相比NeRF快1-2个数量级。 | 
| 高斯椭球 | 3DGS场景表示的基本单元，由一个中心点位置μ和一个3×3的协方差矩阵Σ定义，协方差矩阵决定了高斯在三维空间的形状（拉伸、旋转）和大小。 | 是场景中物体表面、纹理和体积的唯一载体，相比各向同性的球体，椭球可以根据物体的表面几何特征进行拉伸和变形，从而更高效、更紧凑地逼近扁平的表面和细长的结构。 |
| 几何和外观属性 | 位置：高斯椭球在3D空间中的中心坐标； 旋转：通常由一个四元数表示，描述高斯椭球相对于坐标轴的朝向； 缩放：通常是一个3维向量，表示高斯在三个主轴方向上的延伸长度； 不透明度：经过Sigmoid激活函数处理的一个在[0,1]的标量值。 | 位置：确定该高斯存在于空间的哪个地方，构成场景的几何骨架； 旋转：配合缩放使用，控制高斯的方向； 缩放：控制高斯覆盖区域的大小，大尺度的高斯用于表示平滑的背景或大块区域，小尺度的高斯用于表示高频细节； 不透明度：控制高斯的透明度。 |
| 球谐函数（Spherical Harmonics） | 一组定义在球面上的基函数，用于表示高斯的颜色不是固定的，而是随观察方向变化的，阶数越高，能表示的颜色细节越丰富。 | 模拟真实的物理光照现象，如镜面反射、高光和各向异性效应；相较于固定的RGB颜色，SH能大幅提升渲染的真实感。 |
| 可微光栅化（Differentiable Rasterization） | 光栅化过程可微，使得渲染结果可以作为损失函数进行梯度反向传播优化。步骤：1.3D到2D投影：根据相机视图将椭球投影为2D图像平面上的高斯斑点；2.排序：根据深度对高斯进行排序；3.Alpha Blending：按顺序逐个像素地混合颜色和不透明度，生成最终图像。 | 计算渲染图像与真实拍摄图像之间的差异，然后通过反向传播更新位置、旋转、颜色等参数；相比于NeRF需要庞大的神经网络逐点计算光束传输，3DGS的光栅化是基于高度并行的 tile-based rasterization（基于瓦片的光栅化），利用GPU硬件加速，实现了1080p@60fps的实时渲染速度。 |
| Neural Radiance Field（NeRF） | 用MLP将5D坐标（位置+视角）映射到颜色和密度的隐式场景表示，基于体积渲染合成新视角图像。 | 3DGS的前身，质量高但训练慢（小时级）、推理慢（秒/帧），无法实时交互。 | 
| 尺度歧义（Scale Ambiguity） | 在单目视觉几何中，仅凭一张图像或一段视频，无法确定场景中物体的真实大小和距离。如果将整个场景放大一倍，同时将相机的运动轨迹也相应放大一倍，拍摄得到的图像在像素层面上是完全一致的。 | 无法恢复度量深度：单目重建只能得到“深度图”，即知道物体间的相对深度关系，但无法得到真实的米制距离。 尺度漂移：在长时间的SLAM（同步定位与建图）过程中，累积的误差会导致重建出的场景大小发生逐渐的膨胀或收缩。 需外部约束：为了解决这个问题，通常需要引入物体先验大小（如已知人脸宽度）、IMU传感器数据或使用标记点来提供真实的尺度信息。 |
| 遮挡（Occlusion） | 指场景中的物体被其他物体阻挡，导致在相机的视野中无法完全看到。分为自遮挡（物体自身的某些部分挡住了另一部分）和外遮挡（前景物体挡住了背景物体）。 | 观测缺失：被遮挡的区域在图像中没有像素信息，导致重建时出现“空洞”或几何结构不完整。 匹配错误：在多视角几何中，算法容易将遮挡物误认为是背景的一部分，或者试图在不同帧之间匹配实际上看不见的点，导致错误的三角剖分。 渲染伪影：在基于NeRF或3DGS的重建中，如果处理不好遮挡，渲染时会出现“重影”或背景物体透过前景物体显示出来的错误的混合现象。 | RigGS利用3D高斯的特性来处理 |
| 视角不足（Lack of Viewpoints） | 相机在拍摄过程中运动范围太小（基线过短），或者拍摄角度单一（例如纯旋转或纯平移），导致对场景的几何约束不足。 | 三角剖分失败：深度恢复依赖于视差。如果视角变化太小，光线几乎平行，深度的计算误差会急剧增加，甚至趋近于无穷大（深度无法收敛）。  弱纹理区域失效：在视角不足且纹理单一的区域（如白墙），算法无法提取足够的特征点进行匹配，导致地图稀疏或无法定位。 过度平滑：在New View Synthesis（新视角合成）中，视角不足会导致模型倾向于生成模糊、过度平滑的结果，因为它没有看到足够多的细节信息。| RigGS通过引入强几何先验和时序信息来解决：2D骨架投影约束、时序运动信息利用、ARAP（As-Rigid-As-Possible）正则化 |
| 非刚体形变（Non-rigid Deformation） | 被重建的物体在拍摄过程中发生了形状变化或移动（例如随风飘动的衣服、说话的人脸、奔跑的动物），这与传统的静态场景重建假设相悖。 | 破坏几何一致性：传统的SfM（运动恢复结构）假设世界是静态的。非刚体运动会导致算法错误地将物体的位移解释为相机的移动，或者将不同时刻的物体表面强行拟合到一个静态模型上，导致重建结果扭曲、破碎。 建模复杂度高：需要将场景分解为“静态背景”和“动态前景”，或者为每个点引入时间维度的变形参数。这极大地增加了优化的维度和难度（通常使用NRSfM或4D重建技术）。 泛化能力差：非刚体物体的形变模式千变万化，很难像刚体那样用统一的数学模型（如相机位姿）完美描述。 | RiGS解决方法：骨架感知节点形变、线性混合蒙皮、姿态相关的细节变形 |
| 骨架感知节点形变（Skeleton-Aware Node Deformation） | 在初始化阶段，不直接使用刚体变换，而是引入了一组“骨架感知节点”。 | 通过MLP预测这些节点随时间的旋转和平移，并利用反距离加权（Inverse Distance Weighting）来驱动物体上3D高斯的运动。这种方法能够捕捉物体的大幅度非刚性运动（如弯曲、伸展）。 | RigGS Stage1的核心方法 
| 线性混合蒙皮（Linear Blending Skinning/LBS） | 在骨架驱动建模阶段，利用提取出的稀疏骨架和骨骼，通过LBS算法将3D高斯绑定到骨骼上。定义每个顶点（或3D高斯）受骨骼影响的程度的标量值，对于一个顶点，它受所有相关骨骼的影响权重之和通常归一化为1。 | 将物体的大尺度运动分解为骨骼关节的旋转和平移，解决了非刚体运动中整体姿态的估计问题，实现皮肤弯曲时的平滑过渡，避免出现断裂或扭曲。 | RigGS Stage 3用它实现骨骼驱动的动态建模，将自动构建的35关节层次树与Gaussian点绑定，支持任意姿态驱动。 |
| 姿态相关的细节变形（Pose-Related Detail Deformation） | 引入了一个MLP来预测残差偏移。 | 专门用于处理LBS无法模拟的细微非刚体变化，例如衣物褶皱、肌肉收缩等随姿态变化的细节，使重建更加真实。 | 
| 2D骨架投影约束（2D Skeleton Projection Constraint） | 利用图像处理算法（如骨架化/形态学细化）从物体剪影中提取2D骨架点，并将其作为监督信号。 | 计算3D节点投影到2D平面与提取的2D骨架点之间的Chamfer距离。这种约束强制3D结构在有限的视角下也要符合物体的几何中心轴线，极大地补充了视角不足带来的几何约束缺失。 | 
| 时序运动信息利用（Time-series Motion Information Utilization） | 在构建骨架时，利用节点在整个视频序列中的运动轨迹。 | 通过分析节点的运动幅度来构建骨架的连通性（最小生成树），即使某几帧的视角不好，物体运动产生的视差也能帮助算法推断出正确的3D结构。 |
| ARAP（As-Rigid-As-Possible）正则化 |  | 在优化过程中引入ARAP损失，鼓励变形场保持局部刚性，防止在视角缺失的区域出现不自然的扭曲。 |
| 无模板先验 | 传统的SMPL等方法依赖于预设的人体模型，这些模型有固定的尺度。如果视频中的人是个小孩，强行套用成人模板会导致尺度错误。RigGS不需要任何模板，而是直接从视频中优化出 Canonical Shape（规范形状）。这意味着物体的尺度是根据视频内容自身确定的，虽然可能不是真实的物理尺度，但保证了重建物体内部的相对尺度是正确的，且不会受到错误模板的干扰。 |
| D-NeRF（Dynamic Neural Radiance Fields） | 将NeRF（神经辐射场）扩展到动态场景的工作，通常包含两个MLP网络：一个用于预测静态场景，另一个用于预测随时间变化的密度和颜色变化。 | 解决原始NeRF只能处理静态场景的问题，能够对包含移动物体或形变物体的视频进行新视角合成，为后续的动态场景重建提供了基础框架，但通常计算量大且难以解耦几何与运动。 |
| 形变场（Deformation Field） | 一个学习到的向量场或变换函数$T_t$,用于将观察空间（每一帧的特定时刻t）中的点映射回一个规范空间，或者反之。公式通常表示为$x_{canonical}=x_t+\Delta(x_t,t)$。 | 将复杂的动态场景分解为一个静态的“规范几何”和一个随时间变化的“形变场”。这大大降低了学习难度，因为规范几何只需要学习一次，而形变场只需要处理运动。能够有效地模拟衣服飘动、面部表情变化等非刚性形变。 |
| 规范空间（Canonical Space） | 一个假设的、不随时间变化的3D坐标系。在这个空间中，动态物体通常被定义在一个“中性”或“标准”姿态下（例如人体的T-pose，或物体的平均形状）。 |  提供了一致的参考系，使得模型可以在同一套几何结构上存储纹理和外观信息，而不需要在每一帧都重建一遍几何。避免了直接在每一帧中优化独立的辐射场，提高了参数效率和渲染的稳定性。 |
| 时间条件编码（Time-Conditioned Encoding） | 将时间变量t通过正弦位置编码、哈希编码或其他特征映射技术转换成高维向量，输入到神经网络（MLP）中，作为额外的条件输入。 | 让网络能够区分不同时刻的状态。它使得同一个坐标点在不同时间可以产生不同的密度、颜色或形变。允许网络在训练数据之间的时间点进行推理，从而生成任意时间步的平滑过渡视频。 |
| 骨架节点/关节（Skeleton Nodes/Joints） | 3D空间中的离散点，作为物体运动结构的控制中心。它们通常对应于解剖学上的关节（如肩、肘、膝）或机械结构的连接点。 | 作为旋转和移动的锚点。通过改变节点的位置和旋转，可以驱动附着在上面的几何体（皮肤、网格、高斯）一起运动。将数百万个顶点的运动控制简化为几十个关节参数的控制，极大地降低了编辑和动画的复杂度。 |
| 关节层级/骨架层级（Joint Hierarchy/Skeleton Hierarchy） | 一种树状数据结构，定义了节点之间的从属关系。通常有一个根节点，其他节点作为子节点连接。 | 为物体提供了语义化的运动结构（如区分手臂和腿），符合人类对物体运动的理解。定义了运动是如何传递的。当父节点运动时，所有子节点必须跟随运动，这模拟了真实的物理连接。 |
| 父子约束（Parent-Child Constraints） | 在层级结构中，子节点的变换（旋转/平移）是定义在其父节点的局部坐标系中的，而不是世界坐标系。 | 确保物体不会在运动中散架。通过旋转关节角度来计算末端位置的基础，保证了动画的合理性和连贯性。（正向运动学） |
| 运动链（Kinematic Chain） | 从根节点开始，通过父子关系连接的一系列关节和骨骼，一直延伸到末端效应器（End-effector，如手或脚）。 | 一条完整的运动链定义了肢体的一整套运动逻辑。在动画编辑中，如果指定了手的目标位置，IK（逆运动学）算法会利用运动链反推关节需要的旋转角度。运动链是实现IK求解的必要结构。 |
| 骨架变换矩阵（Bone Transformation Matrix） | 一个4x4的齐次矩阵，表示骨骼从绑定姿态到当前姿态的变换，包含旋转和平移信息。 | 将顶点从模型空间（或规范空间）转换到当前的观察空间。 | 矩阵是LBS计算的核心，直接决定了物体的姿态。 |
| 关节旋转（Joint Rotation） | 关节在局部坐标系下的旋转变量，通常用四元数或欧拉角表示。 | 将复杂的运动简化为一系列角度的变化。 | 驱动骨骼变换矩阵的主要参数。 |
| 定点/高斯点绑定（Vertex/Gaussian Binding/Skinning） | 建立几何单元（网格顶点或3D高斯中心点）与骨架骨骼之间的关联关系，并分配相应的蒙皮权重。 | 将静态的网格或高斯点云变成可动的模型。 |
| 先估计大结构（Coarse Structure） | 在算法初期，不尝试精确定位关节点，而是先确定物体的拓扑结构和连通性，常使用FPS（最远点采样）获取分布均匀的点，构建最小生成树（MST），或利用PCA寻找主轴。 | 防止算法陷入局部最优，保证骨架整体的形状是合理的。 |
| 再细化关节（Joint Refinement） | 在粗略结构的基础上，根据几何特征（如曲率突变）、运动特征（如旋转中心）或语义特征（如DINO特征）来识别和精修关键关节点的位置。筛选分支点、端点以及运动轨迹变化剧烈的点作为关节候选。 | 使骨架具有物理意义，能对应真实的关节。 |
| 最后优化蒙皮权重（Skinning Weight Optimization） | 在骨架确定后，不再改变骨架结构，而是通过反向传播优化每个点对每个骨骼的权重参数。 | 修正由于线性近似（LBS）带来的体积损失或扭曲，使重建结果与输入视频更贴合。 |
| 节点偏移（Node Offset） | 在形变场中，控制节点从初始位置移动到目标位置的位移向量$\Delta x$ | 不依赖预设的骨架树，通过节点的自由移动来近似任何复杂的非刚体形变，常用于初始化阶段或处理软体变形。 |
| 局部刚性约束（Local Rigidity Constraints/ARAP(As-Rigid-As-Possible)） | 在优化节点或顶点位置时，施加的一种能量惩罚项，要求局部的几何形状在变形前后尽量保持刚性（距离和角度不变）。 | 防止在剧烈运动或视角缺失时，物体表面发生不自然的拉伸、压缩或翻转，保持物体的材料特性。 |
| 关节附近形变控制（Joint Proximity Deformation Control） | 在形变建模中，区分关节区域和非关节区域。关节区域允许较大的旋转和扭曲，而骨骼中间区域主要进行刚体平移和旋转。 | 针对膝盖、手肘等运动复杂的区域进行专门建模，让关节弯曲处的皮肤褶皱和变形更加符合自然规律。 | 
| 峰值信噪比（Peak Signal-to-Noise Ratio/PSNR） | 基于像素值的误差指标，衡量重建图像与真实图像之间的均方误差（MSE）。值越大越好。$\text{PSNR} = 10 \cdot \log_{10}(\frac{MAX^2}{MSE})$ | 反映了图像的清晰度和像素级别的对齐程度。对像素位置的微小偏移非常敏感，且不能反映视觉感知的相似性。 |
| 结构相似性（Structural Similarity Index Measure/SSIM） | 从亮度、对比度和结构三个维度对比图像的相似度。值范围在[0, 1]之间，越接近1越好。$\text{SSIM}(x,y) = \frac{(2\mu_x\mu_y+c_1)(2\sigma_{xy}+c_2)}{(\mu_x^2+\mu_y^2+c_1)(\sigma_x^2+\sigma_y^2+c_2)}$ | 比PSNR更符合人眼对图像结构的感知。对光照变化和轻微的几何偏移不如PSNR敏感。 |
| 感知相似性（Learned Perceptual Image Patch Similarity/LPIPS） | 利用预训练的深度神经网络（如VGG）提取图像的特征，在特征空间计算距离。值越小越好（表示差异越小）。$\text{LPIPS} = \| \phi(x) - \phi(y) \|_2$ | 模拟人类视觉系统的感知机制。它关注纹理和语义内容，而不是像素误差。 |
| 消融实验（Ablation Study） | 通过系统性地移除或修改模型的某个组件，测量其对整体性能的影响，验证该组件的贡献。 | 科研实验设计的核心方法。 |
| 纯节点形变（Node-only Deformation） | 指仅使用一组自由浮动的控制节点（类似于变形图或BANMo中的神经骨骼）来驱动物体运动，节点之间没有层级或父子约束。 | 
| 骨架驱动（Skeleton Driven Deformation） | 指将节点组织成具有层级的树状骨架结构，并通过LBS等算法进行驱动。 |
| 控制变量（Control Variables/Controlled Ablation） | 在对比实验中，保持所有其他条件（数据集、训练步数、基础网络结构、超参数等）完全一致，只改变一个特定的模块或损失函数。 | 确保最终性能的提升（或下降）确切地是由那个改变的模块引起的，而不是其他干扰因素，逐个验证论文中提出的每个创新点是否真的有效。 |
| 定量对比（Quantitative Comparison） | 使用数值指标（PSNR, SSIM, LPIPS）来衡量消融实验中不同变体的性能，并制作表格进行展示。 | 提供无偏的、可量化的数据支持，避免仅凭人眼主观判断，通过数值的变化幅度，判断该模块对整体系统的贡献程度。 |
| 提出问题 | 发现当前研究领域的空白或现有方法的缺陷。| 确立研究目标，奠定创新基础。 |
| 设计方法 | 针对提出的问题，构建一套技术框架，包含具体的数学模型、网络架构、算法流程或损失函数。 | 提供具体的技术路径，将抽象的想法转化为可执行的代码，确保提出的每个模块都是为了解决对应的问题，形成闭环。 |
| 实验验证 | 在标准数据集上运行提出的方法，并与当前最先进的方法进行对比（SOTA Comparison）。 | 用实验结果证明新方法在解决既定问题上是有效的。 |

| 指标变化 | 观察随着训练进行，或者随着某个超参数/模块的调整，评估指标是如何上升或下降的。 | 如果Loss不收敛或指标震荡，说明训练策略有问题。 |

| 反向过程/去噪（Reverse Process） | 推理（生成）阶段的过程。从随机噪声开始，利用训练好的模型逐步去除噪声。 | 这是用户最终看到图片诞生的过程。每一步去噪都会让图像的轮廓和细节变得更加清晰。 |

| 监督学习（Supervised Learning） | 利用有标签的数据集进行训练。每个训练样本既包含输入数据（特征），也包含对应的正确输出（标签/答案）。 | 目标是学习从输入到输出的映射函数，以便对新的未知数据进行预测。常见任务包括图像分类、线性回归。 |
| 无监督学习（Unsupervised Learning） | 利用无标签的数据集进行训练。只有输入数据，没有预定义的输出标签。 | 旨在挖掘数据内部的模式、结构或分布。常见任务包括聚类、降维、异常检测、密度估计。|
| 过拟合（Overfitting） | 模型在训练集上表现极好，但在测试集或新数据上表现很差的现象。模型记忆了训练数据的噪声和特例，导致泛化能力低。 | 识别：训练 Loss 持续下降，验证 Loss 先降后升。 | 解决：正则化、早停、数据增强、模型简化。 |
| 欠拟合（Underfitting） | 模型在训练集和测试集上表现都很差的现象。模型太简单，无法捕捉数据中的基本规律。 | 识别：训练 Loss 一直居高不下，无法收敛。 | 解决：增加模型复杂度、降低正则强度、使用更复杂的非线性模型、进行特征工程、延长训练。 |
| 早停（Early Stopping） | 在验证 Loss 不再下降时停止训练，防止过拟合。|
| 交叉验证（Cross-Validation） | 将数据划分为k份，轮流用k-1份训练1份验证，重复k次取平均的方法。 | 适用于数据稀缺的场景，避免单次划分偏差。 |
| Dropout | 训练时随机丢弃（置零）部分神经元输出，推理时使用全部神经元。 | 防止过拟合，提供隐式的模型集成效果。 |
| Transformer架构（Transformer Architecture） | 2017年《Attention is All You Need》提出的架构，由堆叠的注意力层和前馈网络层组成，支持并行化训练。 | 当前所有主流大模型的基石。 |
| 多头注意力机制（Multi-Head Attention） | 将输入向量映射为 Q（查询Query）、K（键Key）、V（值Value）三组向量，并通过计算 Q 和 K 的相似度来决定对 V 的关注程度。“多头”是指将输入分别映射到多个子空间并行计算注意力。$\text{Attention}(Q,K,V) = \text{softmax}(\frac{QK^T}{\sqrt{d_k}})V$ | 允许模型在不同位置同时关注来自不同子空间的信息，显著提升模型对复杂序列的表达能力。 |
| 前馈网络（Feed-Forward Layer） | Transformer 编码器/解码器层中位于注意力机制之后的全连接神经网络，通常包含两个线性变换和一个非线性激活函数（如 ReLU 或 GELU）。 | 对注意力机制输出的信息进行深度加工，提升模型的表达能力和非线性拟合能力。 |
| 层归一化（Layer Normalization） | 一种归一化技术，它对单个样本的所有特征进行归一化处理（计算均值和方差），使其符合标准正态分布。$\mu = \frac{1}{d}\sum_{i=1}^d x_i$，$\sigma = \sqrt{\frac{1}{d}\sum_{i=1}^d (x_i-\mu)^2}$ | 相比于批量归一化，LayerNorm 不受 Batch Size 大小限制，处理变长序列更稳定，能有效解决梯度消失/爆炸问题，加速 Transformer 的训练。 |
| 绝对位置编码（Absolute Positional Encoding） | 给序列中的每个位置分配一个固定的向量，直接将该向量加到输入的词嵌入中。Transformer 原论文使用的是正弦和余弦函数生成的固定编码。 | 由于 Transformer 的自注意力机制本身是置换不变的（即不考虑输入顺序），必须显式地告诉模型哪个词在第几个位置。 |
| 相对位置编码（Relative Positional Embedding/RPE） | 一种不直接添加绝对位置向量，而是通过旋转变换将位置信息注入到 Q 和 K 的点积运算中的编码方式。它关注的是两个位置之间的距离。 | 绝对位置编码在遇到比训练时更长的序列时往往效果下降（外推性差）。RPE 侧重于相对位置关系，使得模型更容易处理未见过的序列长度，且能更好地捕捉元素间的相对依赖关系。 |
| 正弦位置编码（Sinusoidal Position Encoding） | 绝对位置编码的一种实现方式。$PE_{(pos,2i)} = \sin(pos/10000^{2i/d})$，$PE_{(pos,2i+1)} = \cos(pos/10000^{2i/d})$ | 为Self-Attention注入序列位置信息，不同频率的sin/cos组合让模型学习任意位置的绝对和相对关系。 |
| 旋转位置编码（RoPE） | 通过将位置信息编码为旋转矩阵：$\text{RoPE}(q_m, n) = R_{m,n} \cdot q_m$，使注意力得分天然包含相对位置关系。 | 比Sinusoidal更好地建模相对位置，长度外推能力更强，被LLaMA/Qwen等主流开源模型采用。 |
| KL散度（KL Divergence） |  衡量两个概率分布P和Q差异的非对称度量：$D_{KL}(P\|\|Q) = \sum_x P(x) \log\frac{P(x)}{Q(x)} $。 | LLM对齐技术（RLHF/DPO）中的核心损失函数，衡量策略分布与目标分布的差异。 |
